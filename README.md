# Rosara Adorn — luxury appointment website

Keep `index.html` and `rosara-logo.jpg` together in the same folder.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload both files to the repository root.
3. Import the repository at https://vercel.com/.
4. Deploy as a static site; no build command is required.

## Included
- Your supplied logo and exact tagline
- Ivory, black and champagne-gold styling
- Responsive landing page and About Us modal
- Eight-step appointment preference flow and confirmation screen

## Production limitations
This is a front-end prototype. Login/signup, database persistence, protected admin dashboard, live availability, appointment notifications, and payment processing are not connected. These need a secure backend and account configuration. Never put database service-role keys or payment secrets in browser code.
